Синтаксис

Пример

название(текст/параметры)(текст/параметры)[подпись 1][подпись 2...]{
    дочерний элемент 1
    дочерний элемент 2
}{
    дочерний элемент из другого списка дочерних элементов
}

У большинства элементов текст внутри элемента можно задать написав (текст), `текст` или "текст" после названия блока.
Например:

start(start1)
start`start2`
start"start3"

Обратите внимание, если вы хотите использовать закрывающий элемент (), ` или ") внутри текста блока, то его нужно экранировать.
Например:

start(function1(a1, a2\))
end

Элементы

Через / написаны варианты имени одного и того же элемента.

start

start
start(Custom)

end / stop

end
end(Custom)

connector

connector
connector(1)

program

Этот элемент улучшает визуальную составляющую кода схемы, заменяя start и end.

program(CustomStart)(CustomEnd){
    data(Hello, world!)
}

process / block

process(x = 0)
block(x = x + 1)

data / io

data(Hello, world!)
io(Hello, world2!)

function / func / fun / def

function`function(a,b,c)`
func`func(a,b,c)`
fun`fun(a,b,c)`
def`def(a,b,c)`

if

Поддерживает 2 и 3 ветки. Названия по умолчанию имеются только для двух. Блок имеет дочерние блоки.

if(x % 2 = 0){
    io(Чётное)
}{
    io(Нечётное)
}
if(x % 2)[0][1]{
    io(Чётное)
}{
    io(Нечётное)
}
if(x и 0)[<][==][>]{
    io(Меньше нуля)
}{
    io(Равно нулю)
}{
    io(Больше нуля)
}

loop

block(x = 0)
loop(pre-text)(post-text){
    io(Тело цикла)
}
io(Done.)

sideLoop

Делает цикл со сдвигом. Если элементов недостаточно, делает обычный loop.

block(x = 0)
sideLoop(pre-text)(post-text){
    block(Тело цикла)
    block(Тело цикла)
}
io(Done.)

for

Делает такой же loop, но при этом реализуя привычный нам for.

for(i = 0)(i < 10)(i++){
    io(i)
}

sideFor

Делает sideLoop из структуры for.

sideFor(i = 0)(i < 10)(i++){
    block(j = i + 1)
    func(print(j\))
}

parallel / join

Имеет неограниченное число дочерних последовательностей элементов. Имеется возможность указать расстояние между последовательностями.

parallel(20){
    start
    connector(1)
}{
    connector(1)
    connector(2)
}{
    connector(2)
    end
}
parallel(20){
    connector(1)
}{
    connector(2)
}{
    connector(3)
}
io(Hello, world!)
end

program{
    left_if(a>b){

    }{
        io(b)
    }
}

right_if

program{
    right_if(a>b){

    }
